Árbol de decisión del sensor

Cómo decide el sistema si un sensor está normal, necesita calibración o necesita mantenimiento.

Sensores
Qué hace y con qué datos

Un árbol de decisión es una serie de preguntas de sí o no sobre las lecturas de una operación, que termina en una decisión. Para cada operación se calculan seis características del sensor (variación entre lecturas, lecturas repetidas, lecturas faltantes, valores imposibles, mayor salto y días desde la última calibración) y se recorre el árbol.

Distingue las fallas del sensor de las del proceso: si la temperatura se desvía pero el sensor se comporta bien (por ejemplo, una deriva del proceso), el diagnóstico es normal, y el problema lo muestra la carta de control SPC.

Límites del modelo
  • Como no hay un sensor real, se entrenó con {{ metricas.muestras_entrenamiento + metricas.muestras_prueba }} operaciones simuladas de sensores sanos y averiados. Demuestra el método, no una capacidad comprobada de predecir fallas reales.
  • La calibración se considera vigente hasta {{ metricas.supuestos.calibracion_vigente_dias }} días: es un supuesto, no un dato del fabricante.
  • Un valor fuera del rango físico es el que queda fuera de {{ metricas.supuestos.rango_fisico[0]|int }}–{{ metricas.supuestos.rango_fisico[1]|int }} °C.
