Cómo se calcula

Cada resultado sale de estas fórmulas con los datos registrados en el sistema.

1. Energía de cada operación
Energía (kWh) = Potencia del equipo (kW) × Tiempo en marcha (h)
2. Emisiones de producción
Emisiones (kg CO₂e) = Energía (kWh) × Factor eléctrico ({{ ("{:.3f}".format(factor_e.valor|float)) if factor_e else '—' }} kg CO₂e/kWh) {% if factor_e %}
{{ factor_e.concepto }} · {{ factor_e.anio }} · Fuente: {{ factor_e.fuente }}
{% endif %}
3. Emisiones de transporte
Emisiones (kg CO₂e) = Peso (t) × Distancia (km) × Factor de transporte (kg CO₂e/t·km) {% if factor_t %}
Factor por omisión: {{ ("{:.4f}".format(factor_t.valor|float)) }} · {{ factor_t.concepto }} · {{ factor_t.anio }} · Fuente: {{ factor_t.fuente }}
{% endif %}
4. Huella e intensidad por unidad
Huella por botella = (Producción + Transporte) ÷ Unidades aceptadas
Intensidad energética = Energía total (kWh) ÷ Unidades aceptadas
